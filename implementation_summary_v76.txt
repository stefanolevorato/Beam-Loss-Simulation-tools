Quartz Cherenkov Simulator v76
Build: build-20260929-v76-gamma-ancestry-energy-audit

Baseline: v75 staged source set, application version 0.43.0. Release version
incremented to 0.44.0. No geometry or UI behavior changes were made.

Gamma transport corrections:
- Secondary charged tracks now receive the current gamma track ID as parent;
  pending Compton and pair-annihilation gammas retain their existing ancestry.
- Photoelectric absorption is no longer added to terminated gamma energy in
  addition to the resulting charged-track energy. The terminated gamma field
  now represents gamma energy discarded below the transport threshold.
- Added deterministic tests for photoelectric, Compton, pair production,
  sub-threshold gamma termination, charged/gamma escape, and track ancestry.

Range-model decision:
- The formula was audited but left unchanged because no authoritative range
  reference or verified derivation was staged and network access was blocked.
- Added a clearly labeled diagnostic/test for its nonmonotonic output:
  R(12.5 keV)=0.419657799 g/cm^2 and R(100 keV)=0.242048532 g/cm^2.
- These are outputs of the current expression, not reference points. See
  gamma_range_model_diagnostic.md for the data needed to justify a future fix.

- Verification passed: Python syntax compilation, all five focused Gamma
